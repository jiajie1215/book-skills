### 毛选人生抉择推演

用《毛泽东选集》中的矛盾分析、调查研究、实践检验和阶段判断方法，帮助分析职业、迁居、婚恋、家庭、创业、学习、财富和人生方向等重要选择。

## 安装

安装单个 Skill：

```bash
npx -y skills add jiajie1215/book-skills -g -s maoxuan-life-decision -y
```

安装仓库中的全部 Skill：

```bash
npx -y skills add jiajie1215/book-skills -g --all
```

安装后可直接调用：

```text
$maoxuan-life-decision
我已经工作8年，主业稳定但成长放缓，我该怎么开启第二曲线？
```
